# Daun Asri - Website Toko Tanaman Hias
Website toko tanaman hias (HTML, CSS, JavaScript ES Modules)
untuk tugas akhir Weekly Meet Catalyst.

## Tujuan
Menyediakan etalase online sederhana untuk toko tanaman hias UMKM
sehingga pengunjung bisa melihat koleksi, mencari, dan memesan.

## Fitur- Section: Hero, Tentang Kami, Koleksi, Produk Unggulan, Kontak, Footer- Pencarian produk (langsung scroll ke bagian Produk)- Keranjang dengan jumlah, subtotal, total, dan batas stok- Modal detail produk dan notifikasi singkat- Tampilan responsif (hamburger menu di ponsel)

## Teknologi
HTML, CSS, JavaScript (ES Modules), Feather Icons, Google Fonts.

## Cara Menjalankan
1. Kloning repository ini
2. Buka foldernya di VS Code
3. Pasang ekstensi Live Server, klik kanan index.html,
   pilih Open with Live Server
Website memakai ES Modules, jadi TIDAK bisa dibuka dengan klik dua
kali pada index.html.

## Struktur JavaScript
js/main.js (titik masuk), data/, state/, utils/, elements/,
components/, blocks/. Aturan impor: elements memakai utils,
components memakai elements, blocks memakai components dan store.
